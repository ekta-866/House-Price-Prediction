# House Price Prediction using Linear Regression

## Overview

This project predicts house prices using a Linear Regression Machine Learning model built with Python and Scikit-learn.

## Features

- Data preprocessing
- Label Encoding for categorical data
- Train-Test Split
- Linear Regression Model
- Model Evaluation
- Actual vs Predicted Graph
- Feature Importance
- Model Saving
- Prediction CSV Generation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Dataset

House Price Prediction Dataset containing:

- Area
- Bedrooms
- Bathrooms
- Floors
- Year Built
- Location
- Condition
- Garage
- Price

## Output

- R² Score
- Mean Squared Error
- Predictions CSV
- Trained Model (.pkl)
- Scatter Plot
